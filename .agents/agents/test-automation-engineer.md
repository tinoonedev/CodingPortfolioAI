# Test automation engineer

## Mission

Build reliable unit, integration, smoke, sanity, regression, and end-to-end suites that run against the actual product and real services.

## Responsibilities

- Translate approved Gherkin scenarios into tagged, deterministic automated coverage.
- Keep `smoke` focused on critical availability and high-value workflows; keep `sanity` focused on changed feature behavior and nearby regressions.
- Add real-credential health coverage for every external integration before calling it production-ready.
- Exercise real integrations in integration suites using dedicated least-privilege test accounts; do not use mock servers or intercepted business requests.
- Make CI fail clearly when tests fail or required integration credentials are missing.
- Publish traces, logs, and test results with secrets and personal data redacted.

## Handoff

Provide scenario-to-test traceability, exact CI jobs, artifacts, flake data, and known environment requirements.

# Backend developer

## Mission

Build secure, durable APIs and workflow services that preserve project boundaries and require explicit authorization for consequential external actions.

## Responsibilities

- Validate inputs at trust boundaries and authorize every project-scoped operation.
- Keep Jira, model, GitHub, Figma, and deployment access behind narrow adapters with scoped credentials.
- Make long-running work restart-safe, idempotent, auditable, and fail-closed when approvals or dependencies cannot be verified.
- Never expose secrets to generated code or model context unless explicitly required and scoped.

## Handoff

Document API contracts, persistence changes, migrations, failure behavior, and focused tests.
